## Installation Steps

### 1. Copy Files to Your Project

```bash
# Copy the src/app files to your project's src/app/ directory
cp -r src/app/environment your-project/src/app/
cp -r src/app/movement your-project/src/app/
cp -r src/app/camera-rig your-project/src/app/

# Copy tools and scripts
cp -r tools/blender your-project/tools/
cp -r scripts your-project/

# Copy documentation
cp -r docs your-project/
```

### 2. Add Dependencies

Add to your `package.json`:

```json
{
  "dependencies": {
    "cannon-es": "^0.20.0",
    "rxjs": "^7.8.0"
  }
}
```

Then:
```bash
npm install
```

### 3. Integrate into Existing Services

Follow **INTEGRATION_GUIDE.md** in the docs folder to:
- Modify `src/app/render/three-scene.service.ts`
- Modify `src/app/drivers/driver-mixer.ts`
- Modify `src/app/recording/recording.service.ts` (1 line)
- Create `src/app/ui/inspector/environment-tab.component.ts` (new)

### 4. Optional: Build Blender Assets

If you have Blender 4.0+ installed:

```bash
# Export apartment data
node scripts/export-apartment-data.mjs

# Build with Blender (creates GLB files)
blender --background --python tools/blender/build_apartment.py
```

Assets will appear in `public/environments/apartment-default/`. The app loads them automatically.

**If Blender is not available:** The procedural TypeScript builder works perfectly as a fallback—no assets needed.

## Testing Checklist

After integration, verify:

- [ ] Avatar spawns in walkable apartment
- [ ] Physics prevents clipping through walls/furniture
- [ ] Keyboard (W/A/S/D) and joystick both work
- [ ] Selfie Cam frames avatar and reacts to device tilt
- [ ] Placed Cam shows fixed frame correctly
- [ ] Director View (V key) toggles; never recorded
- [ ] All Performance Modes work while walking
- [ ] Recording captures only Take Camera
- [ ] Door E key interaction works
- [ ] Low-tier device still runs

See **INTEGRATION_GUIDE.md** for detailed acceptance criteria.

## Support

**Q: Where exactly do these files go?**  
A: See "Directory Structure" above. Each folder already exists in your V-Me project.

**Q: Do I need Blender?**  
A: No. The procedural TypeScript builder works perfectly. Blender is optional (visual enhancement only).

**Q: What if the integration breaks something?**  
A: The changes are additive—no existing code is removed, only extended. See INTEGRATION_GUIDE.md for exactly what modifies.

**Q: Can I test without running Blender?**  
A: Yes. The app works immediately with the procedural builder. Blender can be done anytime.
